Replace the fixed-delay extra recording buffer with a microphone-aware approach that:
1. Continues recording for up to extra_recording_buffer_ms (max time)
2. Monitors audio volume during the buffer period
3. Uses a noise floor estimated from VAD-classified noise frames during recording
4. Stops early when volume drops below threshold (noise_floor * multiplier) for a sustained period
5. Always waits at least MIN_BUFFER_MS before considering early stop

Changes needed:
- src-tauri/src/audio_toolkit/audio/recorder.rs: Add Cmd::SmartStop, noise floor tracking, smart buffer logic in run_consumer, smart_stop() method on AudioRecorder
- src-tauri/src/managers/audio.rs: Modify stop_recording() to use recorder.smart_stop() instead of sleep + stop
- src/i18n/locales/en/translation.json: Update description text
