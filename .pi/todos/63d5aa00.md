## Completed Implementation

### Backend (Rust) - `src-tauri/src/commands/audio.rs`
- Added `start_pronunciation_recording()` command that starts recording with a special `__pronunciation__` binding ID
- Added `stop_and_transcribe_pronunciation()` command that stops recording and transcribes the audio using the loaded model
- Uses existing `AudioRecordingManager` and `TranscriptionManager` infrastructure
- Rejects if a recording is already in progress (won't interfere with regular transcription)

### Backend (Rust) - `src-tauri/src/lib.rs`
- Registered both new commands in `collect_commands![]`

### Frontend - `src/components/settings/AdvancedCustomWords.tsx`
- Added a "Record pronunciation" button (microphone icon) in the expanded word section
- Three-state recording UI: idle → recording (pulsing red indicator) → transcribing (spinner)
- Auto-stops recording after 5 seconds or user can click "Stop Recording"
- Transcription result is automatically added as a pronunciation variant
- Handles duplicates (won't add duplicate pronunciations)
- Shows success/error toasts with appropriate messages
- Reads latest state from store during transcription callback to avoid stale closures
- Proper cleanup on unmount (clears timers)

### Bindings - `src/bindings.ts`
- Added `startPronunciationRecording()` → calls `start_pronunciation_recording`
- Added `stopAndTranscribePronunciation()` → calls `stop_and_transcribe_pronunciation`
